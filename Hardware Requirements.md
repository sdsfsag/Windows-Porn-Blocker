# Performance Requirements for Porn Blocker 3.6 and Higher

The new version of Porn Blocker includes a **background timer** and a **real-time website monitoring feature**. Only **one website-monitoring agent** runs at a time.

On very old or weaker PCs, these background features may slightly affect performance.

*Please note that these requirements apply to version 3.6 and higher. Older versions may use fewer background features but do not include all current protection and monitoring improvements.*

## 🚨 PCs That Might Struggle

| Category                             | Example CPUs                                          |
| ------------------------------------ | ----------------------------------------------------- |
| **Very Old CPUs (10+ years old)**    | Intel Core 2 Duo, Core 2 Quad, AMD Phenom II          |
| **Slow Dual-Core Processors**        | Intel Atom, older Intel Celeron, AMD A4/A6            |
| **Low-Power Mobile CPUs**            | Intel Atom Z8350, Intel Celeron N-series              |
| **CPUs Below 2.0 GHz**               | Older Intel Atom, Celeron and AMD E-series models     |
| **Systems Already Under Heavy Load** | PCs running many background programs at the same time |

✅ **Minimum CPU – At Least Usable**

Intel Core i3 (3rd generation or newer) → Dual-Core, approximately 2.0 GHz

AMD equivalent → Dual-Core, approximately 2.0 GHz

A **64-bit processor** is required.

💡 **Recommended for Best Performance**

Intel Core i3 (5th generation or newer)

AMD Ryzen 3 (1st generation or newer)

Four CPU threads or more are recommended for smooth background monitoring.

---

## 🎮 GPUs That Might Struggle

Porn Blocker does not perform demanding graphics processing. A dedicated gaming GPU is not required.

| Category                            | Example GPUs                                       |
| ----------------------------------- | -------------------------------------------------- |
| **Very Old Integrated GPUs**        | Intel GMA series, very old AMD integrated graphics |
| **GPUs With Poor Browser Support**  | GPUs without proper DirectX 11 drivers             |
| **Unsupported or Outdated Drivers** | GPUs using Microsoft Basic Display Adapter         |

✅ **Minimum Recommended GPU:** A DirectX 11-compatible integrated GPU, such as Intel HD Graphics 4000 or newer.

💡 **Recommended GPU:** Intel UHD Graphics, AMD Vega integrated graphics or any newer dedicated GPU.

The selected GPU mainly affects Windows, the browser and the displayed HTML animation. Website blocking and monitoring do not require a powerful GPU.

---

## 🧠 RAM Requirements

✅ **Minimum RAM:** 4 GB

Windows may already use most of this memory, so performance can be limited.

💡 **Recommended RAM:** 8 GB or more for smooth performance.

---

## 💾 Storage Requirements

Installer size: approximately 1.17 GB

Installed size: approximately 1.2 GB

Required free storage during installation: at least 3 GB

The additional free space is required because the installer and extracted application files temporarily exist at the same time.

---

## ℹ️ Additional Notes

Supported OS: Windows 10 or newer, 64-bit

Not compatible with Linux or macOS

Porn Blocker is currently not digitally signed. Microsoft Defender, SmartScreen or another antivirus program may display an **“Unknown publisher”** warning.

Always verify the official **SHA-256 hash** before restoring files from quarantine or adding an antivirus exception.

---

## ⚠️ Signs of Performance Issues

* **High CPU usage for an extended period**
* **Lag or slow system performance**
* **System overheating**
* **Crashes or freezes**
* **Slow startup of background components**

If you experience performance issues, check Task Manager, close unnecessary background programs and verify that you are using the newest fixed version of the background timer.

---

If you experience performance issues, check your hardware specifications before updating.
